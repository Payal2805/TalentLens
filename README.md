# TalentLens

## AI-Powered Resume Screening & Candidate Evaluation System

TalentLens is an intelligent recruitment platform designed to automate and optimize the hiring process. The system helps recruiters efficiently screen resumes, evaluate candidates, and identify the best talent using AI-driven analysis and candidate ranking.

The platform provides dedicated modules for Candidates, Recruiters, and Administrators, ensuring a seamless recruitment workflow from job posting to candidate selection.

---

## 🚀 Project Overview

Traditional recruitment processes often require recruiters to manually review large numbers of resumes, making hiring time-consuming and inefficient.

TalentLens aims to solve this problem by providing:

* Automated Resume Screening
* Resume Parsing and Skill Extraction
* Candidate Evaluation and Scoring
* Candidate Ranking Based on Job Requirements
* Recruitment Analytics and Reporting
* Role-Based Access Control (Admin, Recruiter, Candidate)
