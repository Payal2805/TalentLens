# 🛡️ Project Introduction

## Abstract

**TalentLens** is an AI-powered Recruitment and Talent Management Platform designed to streamline and simplify the complete recruitment lifecycle for candidates, recruiters, and administrators.

Traditional recruitment processes often involve manual resume screening, scattered application records, time-consuming candidate evaluation, inefficient interview coordination, and difficulty in identifying suitable candidates from a large applicant pool. TalentLens addresses these challenges by combining a structured recruitment workflow with AI-assisted resume analysis and candidate-job matching.

The platform enables candidates to create profiles, upload resumes, analyze their resumes, browse available job opportunities, submit applications, receive notifications, and track applications and interviews. Recruiters can create and manage job openings, review applicants, view detailed candidate information, use AI-based candidate matching and ranking, manage application statuses, and schedule interviews. Administrators can centrally manage users, candidates, recruiters, jobs, applications, and system settings.

TalentLens combines a modern **React + Vite frontend**, **Django REST Framework backend**, **JWT authentication**, and an **AI processing engine** for resume parsing, job parsing, skill extraction, education extraction, experience extraction, and candidate-job matching.

The platform provides an organized, role-based, and AI-assisted recruitment environment that helps reduce manual screening effort and supports recruiters in making faster and more informed candidate evaluation decisions.

**Index Terms:** Recruitment Management, Talent Management, Artificial Intelligence, Resume Analysis, Resume Parsing, Candidate Matching, Candidate Ranking, Job Management, Django REST Framework, React, Vite, JWT, REST API.

* Text cleaning
* Skill extraction
* Education extraction
* Experience extraction

---

Job descriptions are processed to identify relevant requirements from job postings.

The parsed information helps the system compare job requirements with candidate resume information.

---

## 🔷 Candidate Matching

Candidate matching is used to compare the candidate's resume information against the requirements of a particular job.

The result provides an overall matching score that can be used for candidate evaluation.

---

## 🔷 Candidate Ranking

For a particular job, candidates can be ranked according to their matching scores.

This allows recruiters to quickly identify higher-ranked candidates and prioritize candidate evaluation.

The technologies used in TalentLens were selected based on their suitability for modern web application development, API-based architecture, recruitment management, and AI-assisted processing.

### 🐍 Python

Python provides a strong ecosystem for backend development, data processing, PDF processing, and AI-related functionality.

Vite provides a fast development environment and efficient frontend production builds.

JSON Web Tokens provide token-based authentication for secure API access.

### 🗄️ SQLite / PostgreSQL

SQLite is suitable for local development, while PostgreSQL provides a robust relational database option for production deployment.

The Python-based AI processing layer provides resume parsing, job parsing, information extraction, and candidate-job matching functionality.

# 🚀 Local Setup

## Backend

Navigate to the backend directory:

```bash
cd backend
```

Create a virtual environment:

```bash
python -m venv venv
```

Activate the virtual environment on Windows:

```powershell
.\venv\Scripts\Activate.ps1
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run migrations:

```bash
python manage.py migrate
```

Create a superuser:

```bash
python manage.py createsuperuser
```

Run the backend:

```bash
python manage.py runserver
```

Backend:

```text
http://127.0.0.1:8000/
```

---

## Frontend

Navigate to the frontend directory:

```bash
cd frontend
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Frontend:

```text
http://localhost:5173/
```
